Installation & Setup Guide

  1. Download Extension ZIP Archive
    Click the download button above to fetch EthiScan-v1.0.0.zip directly.
  2. Extract Package on Computer
    Right-click EthiScan-v1.0.0.zip and select Extract All... to uncompress the folder.
  3. Load Unpacked in Chrome
    Open Google Chrome, navigate to chrome://extensions/, toggle Developer mode in the top-right corner, click Load unpacked, and select the extracted folder.
  4. Run Evaluation Scan
    Navigate to any terms or policy page (e.g., Instagram, Facebook, Google, ChatGPT) and press Ctrl + Shift + Y or click the EthiScan extension icon!
